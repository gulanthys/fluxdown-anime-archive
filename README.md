# 文件分类归档

版本 **1.6.3**。插件标识仍为 `gulanthys@anime-archive`，已安装用户可原位升级。

## 保存目录

在插件基本设置中选择「归档方式」：仅按分类（默认）、仅按完成日或月、先按分类再按完成日或月。不提供分类预览。

日期模式仅在宿主提供 `completedDate` 时启用；不支持时仍仅按分类。仅按日期时使用默认下载目录；组合模式在分类目录下追加日期，分类不可用时使用默认下载目录。BT 保留仅按分类的行为。

请在 **FluxDown → 设置 → 下载 → 自定义分类** 中管理分类保存目录。

插件用稳定的内置分类 ID 请求分类，不用 ID、界面语言或译文拼接路径。FluxDown 使用任务提交时配置的内置分类保存目录：设为 `Downloads/图片` 就使用 `Downloads/图片`，设为 `Downloads/写真` 就使用 `Downloads/写真`。切换界面语言不会更改已保存的路径。当前宿主的「一键分类目录」会给内置分类生成英文名；如需中文目录，请在宿主中编辑该分类的保存目录。插件不覆盖已有目录，也不创建英文分类目录。

## 分类规则

- 依据文件内容区分视频、音频、文档、图片、程序和压缩包，不按文件名、扩展名、来源或语言猜测。例如实际为 PNG 的 `photo.txt` 请求图片分类。
- 仅按分类时，无法识别内容，或分类隐藏、缺失、未配置保存目录，插件不请求移动。手动指定目录的任务和任务组不参与插件归档。
- BT 任务首次完成时，只有恰好选中一个非填充文件才可按内容归档。FluxDown 负责迁移整个任务根目录并恢复做种；多选或移动冲突时保留原位置。
- 需要 FluxDown 0.6.5 或更高版本，且归档上下文必须提供 `categoryRouting: true`。宿主负责路径校验、冲突处理和文件移动。
